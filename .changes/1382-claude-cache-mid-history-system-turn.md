### Fixed
- **Claude prompt cache no longer breaks on mid-history system reminders** — a `role: system` turn in the middle of the history (Claude Code's system-reminders) was folded into the top-level `system` field, which sits before `messages` in Anthropic's cache order, so every new reminder re-billed the whole history as cache writes. The text now joins the adjacent user turn (after any `tool_result` blocks) as a `<system-reminder>` block; the `system` field is only used when no neighbouring user turn exists. The remaining Claude-lane request rewrites now marshal with sorted keys so their output is byte-stable across turns.
