### fix(muse-web): normalize exported JSON cookie inputs
- Muse Web (muse.ai) is a cookie-based provider whose credential is the site's session `Cookie` header (it carries `hatch_sess`). Operators paste that credential as a plain header or as a Cookie-Editor JSON export — a bare array `[{"name":"hatch_sess","value":"..."}]` or an object `{"cookies": [...]}`. The semicolon-delimited cookie parser only understood the header form, so an exported jar was rejected as a missing `hatch_sess` cookie and session renewal sent a malformed `Cookie` header.
- `browsercookies.NormalizeCookieHeaderInput` renders a JSON array or `{cookies: [...]}` export as `"name=value; ..."`, preserves an ordinary header string (including `=` inside values), and rejects malformed or unsupported JSON with an informative error before any request is made. This is the shared normalizer the Muse Web credential validation, identity probe and session renewal read on the way in, so a saved JSON credential works without resaving.
