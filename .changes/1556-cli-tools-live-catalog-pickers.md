### Features
- **combos**: The model picker reads the live catalogue for the CLI-tool providers (`commandcode`, `claude`, `zed`, `cursor`, `cline`/`clinepass`) instead of the static registry snapshot, so a model added upstream is selectable without waiting for the next bundle (`decolua/9router@9fb84c94f`, `decolua/9router@69d51c0c3` parity).
- **models**: `GET /api/providers/<id>/models` enriches every live catalogue entry with the server-resolved capability block (`contextLength`, `maxOutput`, `isVL`, `isReasoning`, `thinking_levels`) via `providers.GetCapabilitiesForModel` / `providers.GetThinkingLevels`; a value the feed states itself wins, and an empty thinking-level list is omitted.
- Verified with `internal/handlers/dashboard/connection_models_caps_test.go` (enrichment per input shape, CommandCode/Claude contract, parity with `/api/models/caps`), `web/src/components/combos/pickerData.test.ts` (live entries with caps, static fallback on an empty live list) and `web/e2e/picker_live_catalog.e2e.ts` (live-only pill rendered in Chromium with the resolved caps).
